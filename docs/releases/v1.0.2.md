# Release v1.0.2

[![GitHub Downloads](https://img.shields.io/github/downloads/alexdelprete/ha-droplet-plus/v1.0.2/total?style=for-the-badge)](https://github.com/alexdelprete/ha-droplet-plus/releases/tag/v1.0.2)

**Release Date:** 2026-10-04

**Type:** Patch release - Sub-cent water tariffs and the pydroplet 2.4.1
consumption fix.

## What's Changed

### Changed

- **Water tariff accepts values below one cent.** The tariff was limited
  to 0.01 steps, so low per-gallon rates such as $5.50 per 1000 gal
  ($0.0055/gal) could not be entered. Setup and the options now accept any
  precision, and the *Water tariff* entity uses 0.0001 steps. Reported in
  #20 — thanks to [@stmille](https://github.com/stmille) for the request!
- **Home Assistant 2026.8.0 or newer is now required** (was 2026.3.0).
  HACS does not offer this update on older Home Assistant versions.
- **pydroplet requirement raised to 2.4.1**, so existing installs are
  upgraded to the release that contains the fix below.
- The options flow now uses Home Assistant's current base class instead of
  one that is being phased out. No visible change.

### Fixed

- **Consumption totals are no longer inflated when more than one Droplet
  connection is active** in the same Home Assistant instance, for example
  with two Droplet devices. pydroplet 2.4.1 keeps volume accumulators per
  connection instead of sharing them between all connections
  ([Hydrific/pydroplet#7](https://github.com/Hydrific/pydroplet/issues/7)).

### Known Issues

- **Do not run the core Droplet integration alongside Droplet Plus.** Core
  still pins pydroplet 2.4.0, which lacks the fix above, while Droplet Plus
  now requires 2.4.1. Until core updates its pin, run only one of the two
  integrations.
